# MarketGuard 1.5.0-beta.2

**This is a beta release.** 
> Please report HUD, API, or auction-protection issues with the relevant Minecraft version and log output.

## Fixed

- Player HUD data now loads reliably through HTTP/1.1 connections.
- Reduced repeated blacklist checks and related console spam while the Player HUD is open.
- The UUID row remains visible in the Player HUD's `profile` preset.
- The Player HUD now automatically uses the selected SkyBlock profile when no profile is specified.
